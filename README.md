# URNIMBAS — Streetwear Invoice Generator

A minimalist, raw luxury, mobile-first invoice and bill generator web application designed for streetwear brand **URNIMBAS**.

## Features
- **Raw Streetwear Aesthetic**: Industrial monospace typography, corner targets, SVG barcodes, and off-white/cream palette.
- **100% Mobile Responsive**: Touch-friendly card-stacking on smartphones, scaling up to an A4 ledger on desktop.
- **In-Place Inline Editing**: Edit customer names, phones, invoice numbers, items, prices, and quantities directly.
- **Real-Time Auto Calculation**: Instant calculation for line items and grand totals.
- **UPI QR Code & Brand Terms**: Integrated UPI QR placeholder and strict streetwear policy terms.
- **Clean PDF / Print Export**: Strips out buttons, toolbars, and background artifacts on print.

## Tech Stack
- React 18
- Tailwind CSS
- Lucide React
- Vite
